# Contributing to Android Project Doctor

Thank you for your interest in contributing!

We welcome bug reports, feature suggestions, documentation improvements, and code contributions.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Create a feature branch.
4. Make your changes.
5. Run the automated tests.
6. Submit a pull request.

## Requirements

- Node.js 18 or later
- Git

## Development Setup

Clone the repository:

    git clone https://github.com/aybel007/android-project-doctor.git
    cd android-project-doctor

## Testing

Run the automated tests:

    npm test

Check JavaScript syntax:

    node --check src/index.js
    node --check src/compatibility.js

Please ensure all tests pass before submitting changes.

## Pull Requests

- Explain what your changes do.
- Describe related issues.
- Include tests for new functionality where practical.
- Keep pull requests focused.
- Do not include unrelated files or personal configuration.

Thank you for helping improve Android Project Doctor!
